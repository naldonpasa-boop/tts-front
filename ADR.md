# Контекст проблемы:
В рамках irl d&d игр, использование реального стола для сложных боевых сцен - не оптимально и не удобно. Игрокам сложно дотянуться до миниатюры, трекинг дистанций перемещения перестает играть реальную роль, игрок не видит поля боя постоянно и удобно. 


# Предлагаемое решение
Предлагаемое решение для проблемы -  веб приложение, хостящееся на машине в рамках локальной сети, отрисовывающее сетку и позволяющее перемещать картинки (токены) по ней. 

Игрокам предлагается управлять токенами через клиент игрока, либо тривиальный веб, либо бот в мессенджере. Сервер обрабатывает события и сохраняет их. Фронт составляющая приложения несколько раз в секунду опрашивает сервер на изменения состояний, после чего обновляет сцену, двигая игровые токены.
